# Diabetic Retinopathy Detection Using Deep Learning

## About the Project
This project aims to detect diabetic retinopathy from retinal images
using deep learning and image preprocessing techniques.

## Objectives
- Preprocess retinal images for model training.
- Develop a deep learning model for classification.
- Evaluate model performance using suitable metrics.
- Predict the severity class of diabetic retinopathy from retinal images.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- OpenCV
- Matplotlib
- Jupyter Notebook

## Project Structure
- notebooks/: Model training and preprocessing notebooks.
- src/: Source code for prediction.
- data/: Dataset information.

## Installation
Install the required libraries using:

pip install -r requirements.txt
